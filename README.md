# Prompt to Pocket

An animated showcase of Claude Code building a mobile app (an IT service request app), told in four scenes.

**Status:** Phase 0 prototype, for stakeholder feedback.

| Scene | Claude Code feature | What happens |
|---|---|---|
| 1. Plan | Plan mode | A one-sentence prompt becomes a 5-step plan that waits for approval |
| 2. Subagents | Parallel subagents | Three helpers (UI, API, Tests) work at the same time while the phone builds itself |
| 3. Self-heal | Run tests, fix failures | A failing test, a bug crawling on the phone (tap to squash), a one-line fix, tests turn green |
| 4. Ship | Permissions, git, CI | A human approves the push, CI checks pass, the app launches and a notification arrives |

## Run it
Open `prototype/index.html` in any browser. No build step and no dependencies.

- **Back / Next**, arrow keys or swipe to move between scenes
- **Play Director's Cut** loops all scenes for kiosks and townhalls
- Respects the device's reduced-motion setting
